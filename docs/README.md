# Dokumentasi OTRIS AI

Proyek ini terdiri dari backend FastAPI dan frontend React/Vite.

## Backend

Backend berada di folder `backend/` dan menyediakan API chat untuk komunikasi dengan model OpenAI.

## Frontend

Frontend berada di folder `frontend/` dan menjadi antarmuka pengguna untuk panel touchscreen besar.

## Penggunaan

- Jalankan backend dari folder `backend/`
- Jalankan frontend dari folder `frontend/`
- Pastikan API key OpenAI tersimpan di `.env`

## Struktur Folder

- `backend/` — kode FastAPI dan dependency Python
- `frontend/` — project React/Vite dan asset UI
- `docs/` — dokumentasi tambahan
